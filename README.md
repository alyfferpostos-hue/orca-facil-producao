## Publicação futura
Não foi alterado o GitHub nem o Render. Quando decidir publicar, substitua os cinco arquivos originais na raiz do repositório e acrescente os seis novos. O Render conectado ao GitHub fará o deploy.

O contato usa GitHub Issues (público), pois não foi fornecido um e-mail de suporte. Revise este canal se quiser um contato privado. Se ativar anúncios, confira as exigências de consentimento do Google e da LGPD. Publicar uma política não garante aprovação no AdSense.
